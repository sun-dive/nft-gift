# nft.gift — the card maker

**Make your card immortal.**

A self-contained, single-file web app for making personalised, self-animating
greeting cards — drawn in the browser, owned on-chain, sent as a private gift.

- **Free** — draw + download a self-contained, shareable card.
- **Paid (optional)** — mint to chain + a private, recoverable gift-link.

Cards are **Front + Inside + Back**, portrait 3:4; branding + provenance live on
the Back. Private, person-to-person — not a marketplace.

Forked from the create.nft.sale draw tool and diverging into its own product
(the draw tool continues as the 3D multiverse wall-spray canvas).

## Deploy
Fully self-contained: `index.html` has all CSS/JS inline — no build, no
dependencies. cPanel Git Version Control copies it to the nft.gift document
root (see `.cpanel.yml`).
